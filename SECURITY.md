# Security Policy

This repository is an educational Jenkins CI/CD lab for a Java web application.
It is sample code and pipeline configuration for learning—not a hosted service
or production deployment.

## Scope

**In scope:** security issues in source, manifests, workflows, and documentation
in this repository.

**Out of scope:** vulnerabilities in Jenkins, EKS, or other infrastructure you
deploy yourself; the companion
[`devops-install-scripts`](https://github.com/T-Py-T/devops-install-scripts)
Terraform lab; and upstream products unless this repo’s configuration clearly
introduces or worsens the issue here.

## Reporting a Vulnerability

If you discover a security issue in this repository, please report it privately:

- **Email:** [tnt850910@aol.com](mailto:tnt850910@aol.com)
- **GitHub:** [Private vulnerability reporting](https://github.com/T-Py-T/Full-Jenkins-CICD-Java-WebApp/security/advisories/new) for this repository.

Please include a clear description of the issue, steps to reproduce (if
applicable), and any relevant context.

## What to Expect

We will acknowledge your report and review it as promptly as we can. This is a
personal learning project, so there is no formal SLA or bug bounty program.

Thank you for helping keep this lab safe for others to learn from.
